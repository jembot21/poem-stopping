# Holding My Place in Line

An entry for the make.fun bounty [“The poem about stopping”](https://make.fun/bounty/the-poem-about-stopping-20261121-1927): a poem about agency—the power to stop and to stay.

`main.py` writes the poem to `/output/entry.txt` when run:

```sh
python3 main.py
```

To choose a different output directory, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
